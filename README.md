and Tailwind CSS to showcase my skills, projects, DSA practice, and
contact information.

🌐 Live Portfolio: https://amit-portfolio-three-alpha.vercel.app/

✨ Features

Responsive design for desktop, tablet, and mobile

Modern dark-themed UI with cyan and purple accents

Sticky responsive navigation with mobile menu

Hero, About, Skills, Projects, DSA, Contact, and Footer sections

Resume access directly from the portfolio

Project cards with live demos and GitHub repositories

Interactive hover effects

Developer-focused skills and project showcase

⚙️ Getting Started

Prerequisites

Make sure Node.js and npm are installed.

Installation

git clone https://github.com/Amit01verma/amit-portfolio.git
cd amit-portfolio
npm install

Run Locally

npm run dev

Production Build

npm run build

Preview Production Build

npm run preview
